# Decisões em aberto

Use esta lista para resolver o funcionamento e o visual antes de implementar. As opções descritas nos demais documentos não contam como decisões aprovadas.

| ID | Tema | Decisão necessária |
| --- | --- | --- |
| D01 | Usuários | Apenas supervisores ou funcionários também terão acesso? Haverá um administrador separado? |
| D02 | Operação | Quantos funcionários, supervisores, postos e funções serão cadastrados? |
| D03 | Escala | Como informar a referência inicial e registrar uma mudança definitiva de escala? |
| D04 | Turnos | Confirmar todos os horários, especialmente o período de 18h às 8h. |

| D10 | Estatística | Como tratar não respondidos, cancelamentos, desistências, histórico vazio e correções? |
| D11 | Prioridade | Qual regra de desempate, período do histórico e quantidade mínima de convites? |
| D12 | Efeito da FT | A FT mantém a escala-base? Como registrar uma alteração autorizada? |
| D13 | Correções | Quem pode editar registros passados e como resolver mudanças simultâneas? |
| D14 | Internet | Apenas uso conectado ou suporte a lançamentos pendentes sem conexão? |
| D15 | Design | Qual identidade visual, navegação e conjunto inicial de telas? |
| D16 | Plataforma | Aplicativo nativo, web instalável ou outra solução? Quais aparelhos precisam ser atendidos? |
| D17 | Tecnologia | Qual linguagem, banco de dados e serviço de hospedagem após fechar requisitos? |
| D18 | Entrega | Quais funções entram na primeira versão e quais ficam para depois? |
| D19 | Comercial | Venda sob medida ou assinatura? Quem terá o código e qual será o suporte? |

## Registro de decisões futuras

Ao resolver um item, registre a data, a decisão, a orientação do responsável e os documentos alterados. Atualize o requisito correspondente para manter uma única regra vigente e preserve o contexto necessário no histórico do Git.

Nesta preparação, nenhuma das decisões acima foi resolvida automaticamente.
